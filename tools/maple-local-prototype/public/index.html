본인 Chrome 연결

  2. chrome://extensions에서 개발자 모드를 켜고 압축해제된 확장 프로그램 로드 → 이 폴더의 extension을 선택합니다.

30분마다 새 매물 확인

기존 결과를 기준선으로 저장하고 이후 새 매물만 이 화면의 수신함에 남깁니다. Windows PC·Chrome·로컬 서버가 켜져 있어야 합니다. 재시작하면 감시 설정은 사라집니다.
