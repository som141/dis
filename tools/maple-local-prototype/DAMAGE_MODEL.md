# 장비 교체 기대 피해 계수

2026-11-04 수정. 계산 대상은 화면에 표시된 본인 캐릭터다. 다른 캐릭터의 전투력 증감 필드를 대용으로 쓰지 않는다.

## 계산 범위

동일한 공격·대상·버프 조건에서 장비 한 부위를 교체했을 때의 기대 피해 계수를 비교한다. 반지·펜던트는 각 슬롯을 따로 계산한다. 전투 전체 DPM, 환산 점수, 보스 클리어 시간은 계산하지 않는다. 무기 종류 변경, 쿨감 변화, 특수 반지, 스킬 레벨·재사용 등 모델이 없는 잠재 변화, 미지원 세트, 제논·데몬어벤져의 특수 스탯은 숫자 대신 미계산 이유를 반환한다. 한 매물의 해석 실패가 다른 매물의 계산을 없애지 않는다.

일반·에디 잠재의 ‘쓸만한 ○○ 스킬 사용 가능’ 줄은 기존 장비와 매물 양쪽에서 스킬을 새로 켜거나 끄는 효과로 환산하지 않는다. 같은 캐릭터·버프 조건을 유지한 채 나머지 잠재, 장비 스탯, 세트 변화를 모두 계산한다. 스킬 사용 가능 여부만 바뀌면 교체 증감률은 0%다. 다른 미지원 효과도 함께 바뀌면 그 사유는 계속 표시한다.

## 기본식

`계수 K = S × A × D × C × R × F`

| 기호 | 의미 |
| --- | --- |
| S | 일반 직업은 `4 × 최종 주스탯 + 최종 부스탯`. 카데나·섀도어·듀얼블레이드는 추가 부스탯을 포함 |
| A | 직업에 맞는 최종 공격력 또는 마력. 에반은 마력을 사용 |
| D | `1 + (데미지 + 보공 + U × 상태이상 추가 데미지)/100` |
| C | `1 + (35 + 추가 크뎀)/100`. 사용자 요청에 따라 전후 크확을 모두 100%로 고정 |
| R | `max(0, 1 - 대상 방어율/100 × 방무가 남긴 비율)` |
| F | 개별 최종 데미지 배율의 곱 |

`증가율 = (교체 후 K / 교체 전 K - 1) × 100`이다. 전후에 같게 유지되는 무기 상수·숙련도·동일 스킬 계수 등은 상대 비교에서 상쇄한다. 바뀌는 조건이 있으면 이 전제를 적용하지 않는다. 대상 방어율 기본값은 380%이며 사용자가 변경할 수 있다. U는 대상 상태이상 추가 데미지 적용 체크에 따라 0 또는 1이다. 데미지 상한, 스킬별 방무·크확, 버프 가동률, 속성·포스·레벨 차이의 변화는 별도 전투 모델이 필요하다.

기존 분해 스탯의 기본 크뎀에는 이미 35가 들어 있다. 분해 모델 계산에서 다시 35를 더하지 않는다. API의 추가 크뎀에는 기본 35가 포함되지 않으므로 API 기준 계산에서는 35를 한 번 더한다. 관측된 크확이 100% 미만이거나 장비 교체로 크확이 변해도 이 비교에서는 100%를 사용한다. 크확만 바뀌는 장비의 개선율은 0%다.

## API 기준값에 변화량 적용

수집한 패시브·조건부 버프를 모두 더한 재구성 스탯은 실제 API 총스탯과 달랐다. 재구성값을 현재 스탯으로 사용하는 방식을 중단했다. 캐릭터 API의 실제 총스탯을 기준으로 유지하고 장비·세트에서 바뀌는 양만 적용한다.

- 스탯: API 기준값을 T₀, % 미적용 스탯을 N₀/N₁, 기존/새 총 스탯%를 p₀/p₁, % 적용 전 장비 고정 스탯 변화량을 ΔB라고 할 때, `T₁ = floor(((T₀-N₀)/(1+p₀/100)+ΔB)×(1+p₁/100))+N₁`이다. 심볼 등 % 미적용 스탯을 분리한다.
- 공마: API 최종 공마를 기존 공마%로 나눈 기준에 장비 고정 공마 변화량을 더하고 새 공마%를 적용한다.
- 데미지·보공·크뎀: API 기준값에 장비·세트 차이만 더한다. 유효 크확 및 크리티컬 리인포스 입력 크확은 전후 모두 100%다. 100%를 넘는 실제 크확의 추가 효과까지 계산하는 모델은 아니다.
- 방무: API 기준 잔여 방어 비율에 `새 분해 방무 잔여 곱 / 기존 분해 방무 잔여 곱`을 곱한다. 방무 100% 효과 제거로 비율을 복원할 수 없으면 계산하지 않는다.
- 최종뎀: API 기준 배율에 `새 분해 최종뎀 곱 / 기존 분해 최종뎀 곱`을 곱한다.
- 세트: 개수가 같으면 현재 API 효과를 그대로 보존한다. 개수가 바뀌면 캐릭터 API의 전체 세트 단계 자료를 우선 사용하고, 새로 진입하는 확인된 세트는 규칙표로 계산한다. 미지원 세트는 계산하지 않는다.

스탯·공마% 및 % 미적용 스탯의 분해가 완전하다는 조건이 필요하다. API 총스탯을 기준으로 맞췄다고 해서 수집되지 않은 퍼센트 효과·미지원 스킬까지 검증됐다는 뜻은 아니다. 계산 근거에 기준 방식, 각 계수 전후 값, 분해 모델과 API의 차이, 제외 범위를 함께 저장한다. 공개 API 지연·버프 상태의 차이도 고려해야 한다.

예: 현재 추가 크뎀 111.2%, 유효 크확 100%에서 다른 조건 없이 크뎀 8%만 더하면 크리티컬 계수는 `2.462 → 2.542`, 이 계수만의 상승률은 약 3.25%다. 이는 크뎀 8%가 최종 피해 8% 증가와 같지 않음을 보여주는 단일 요인 예시다.
