# 메이플 개인 로컬 프로토타입

본인의 공식 경매장 로그인 세션으로 **캐릭터 선택 → 매물 검색 → 장비 교체 성능 비교 → 30분 감시**를 실행한다. Windows PC의 Chrome 또는 Linux 도커의 서버 브라우저를 사용한다. 기본 캐릭터는 `에반이였솜`이다. 기존 Discord 봇과 독립적으로 실행한다.

실행 방법은 두 가지다. **Linux 서버에서 계속 실행하려면 [도커 실행 안내](DOCKER.md)**를 사용한다. 서버 브라우저를 원격 화면으로 열어 직접 로그인하며 Windows PC를 계속 켜 둘 필요가 없다. 아래 Windows 직접 실행 방식은 로컬 웹 앱과 Chrome 확장을 사용한다. 두 방식 모두 넥슨 로그인은 공식 웹 경매장에서 진행하며 Nexon Open ID 앱 승인이나 Discord 연동은 포함하지 않는다.

## Windows에서 실행

필요한 도구: **Node.js 22 이상**, 최신 **Chrome**. Java·Docker·Discord 토큰은 필요 없다.

1. 이 디렉터리를 다운로드/압축 해제하거나 저장소에서 `tools/maple-local-prototype`을 연다.
2. **`start-windows.cmd`를 더블클릭**한다. 최초에는 고정 버전 의존성을 설치하고 계산 코드를 빌드한다.
3. 자동으로 열린 주소가 아직 연결되지 않으면 새로고침한다. 주소는 **http://127.0.0.1:8877** 이다. 실행한 터미널은 유지한다.
4. Chrome 주소창에 `chrome://extensions`를 입력한다. 개발자 모드 → **압축해제된 확장 프로그램 로드** → 이 디렉터리의 **`extension`** 폴더를 선택한다.
5. 로컬 웹 화면에서 **연결코드 복사** → 확장 아이콘을 눌러 연결코드 입력 → **로컬 연결**. 확장 포트는 기본 `8877`이다.
6. **공식 넥슨 경매장 로그인**을 열고 본인 계정으로 로그인한다. 로그인·OTP·추가 인증은 공식 화면에서 직접 한다. 해당 탭은 열어 둔다.
7. 로컬 화면의 **연결 확인** → 본인 캐릭터 목록의 **에반이였솜** → **이 캐릭터로 비교**를 누른다. 목록에 없다면 자동으로 다른 캐릭터를 사용하지 않는다.
8. **계산용 넥슨 API 키 설정**에 본인이 발급한 Open API 키를 넣고 **메모리에 적용**한다. 키를 채팅·소스 파일에 붙여 넣지 않는다. **착용 장비 조회** 또는 **캐릭터 새로 갱신**으로 데이터를 확인한다.
9. 아이템 이름·부위·예산·잠재 조건을 입력해 **새 검색**한다. 기본 예산 30억의 검색 범위는 **21억~39억**이다.

키 없이도 웹 경매장 검색은 가능하다. 교체 점수에는 공식 공개 캐릭터 데이터 키가 별도로 필요하다. 첫 캐릭터 데이터 조회는 API 요청 간격 때문에 약 30~60초 걸릴 수 있다. 앱은 키를 파일·localStorage에 저장하지 않으며, 서버 종료/키 지우기로 메모리에서 제거한다.

PowerShell로 직접 실행할 수도 있다.

```powershell
cd tools\maple-local-prototype
npm ci --ignore-scripts
npm run build
npm start
```

Linux/macOS에서도 같은 npm 명령으로 실행할 수 있다. 이 **npm+확장 모드**는 Chrome과 Node 서버를 같은 PC에서 실행한다. [도커 모드](DOCKER.md)는 Linux 서버 안의 브라우저에서 별도로 로그인하며, Windows 로그인 세션을 복사하지 않는다.

## 계산·검색 결과 읽기

- 매물 이름·개당 메소·스타포스·잠재·에디·추옵·거래 설명을 보여 준다.
- 지원되는 매물은 해당 캐릭터의 착용 장비를 교체한 독립 모델의 개선율을 계산한다. 현재 장비는 100점이며 `100 + 개선율(%)`로 비교 점수를 표시한다.
- 가성비는 **개선율 / 가격(억)**이다. 현재 페이지에서만 비교하며 전체 시장 최고 순위를 뜻하지 않는다.
- 반지·펜던트는 모델이 계산한 교체 후보 슬롯 중 개선율이 가장 큰 슬롯을 표시한다.
- 점수가 없으면 0점으로 대체하지 않는다. 키 없음·착용 불가·지원하지 않는 부위·데이터 오류 가능성을 표시한다.
- **환산주스탯의 템환산과 동일한 계산이 아니다.** 사용한 모델의 보스 방어율 가정은 380%다. 직업 스킬·쿨감·버프 등 모든 실전 변수를 재현한다고 보장하지 않는다.
- 에반이 마력 축을 사용하는 것과 툴팁 → 장비 교체 → 개선율 계산은 테스트했지만, `에반이였솜`의 실제 계정·최신 장비·매물로 검증한 결과는 아니다.

캐릭터 원본 응답은 이 앱 폴더의 **`.data/nexon-api`**에 캐시한다. 다른 메이플 도구의 캐시와 분리하며, Git·배포 ZIP에 포함하지 않는다. 여기에 API 키나 로그인 쿠키를 저장하지 않는다. 앱의 로컬 확인 시각은 원본 게임 데이터의 갱신 시각을 의미하지 않는다. 최신 데이터가 필요하면 **캐릭터 새로 갱신**을 누른다. 기본 캐시 경로를 바꾸려면 `MAPLE_AUCTION_DATA_DIR`를 사용한다.

## 30분 감시

판매 중 매물을 검색한 뒤 기간(1/3/7일)과 최소 개선율을 정하고 **현재 검색으로 감시 시작**을 누른다. 개선율 0은 입력한 스펙 조건만 사용한다.

- 최초 결과는 기준선으로 저장하며 기존 매물을 한꺼번에 알리지 않는다.
- 30분마다 **새 검색 POST**를 생성한다. 오래된 searchKey가 새 매물을 반영한다고 가정하지 않는다.
- 조건 1개당 정기 검색은 하루 48회이며 최초/수동 검색은 별도다. 일일 잔여량이 없거나 확인되지 않으면 새 검색을 하지 않는다.
- 현재 프로토타입은 **단일 감시**, **전체 결과가 한 페이지에 담기는 조건**만 지원한다. 전체 결과가 더 많아지면 조건 조정을 요청하고 감시를 중단한다.
- 새 매물은 로컬 웹 수신함에 남긴다. Discord DM·OS 푸시·자동 구매는 포함하지 않는다.
- Windows 직접 실행에서는 PC·Chrome·Node 프로세스가 켜져 있어야 한다. 도커 모드는 서버·컨테이너·서버 브라우저를 유지한다. 절전·종료·연결 끊김에는 확인이 지연/중단된다. 놓친 회차를 몰아서 실행하지 않는다.
- 서버 재시작 시 연결코드·키·감시·수신함은 초기화된다. Chrome 프로필/연결이 바뀌면 기존 캐릭터·검색을 무효화하고 재확인을 요구한다.

등록에서 알림까지 30분 이내를 보장하지 않는다. 제공자 반영 시간·오류·한도에 따른 지연, 확인 전에 팔린 매물 누락이 있을 수 있다.

## 오류 확인

| 상태 | 조치 |
| --- | --- |
| 확장 연결 대기 | 같은 PC인지, 실행 포트와 연결코드가 맞는지 확인. 서버 재시작 후 코드를 다시 입력 |
| 세션 만료·401/403 | 공식 경매장 탭을 열거나 새로고침하고 로그인·OTP를 완료한 뒤 연결 확인 |
| 캐릭터 목록에 이름 없음 | 다른 넥슨/메이플 계정인지 확인. 임의 ID/OCID를 입력해 대신 사용하지 않음 |
| HTTP 426 | 웹 내부 API 버전이 변경됐을 수 있음. 반복 호출하지 말고 호환성을 점검 |
| 검색 결과 0건 | 이름·부위·가격·옵션 조건 확인. 결과가 없어도 검색 횟수 차감 가능 |
| 검색 한도 소진 | 수동 검색을 멈추고 초기화 후 검색·감시를 다시 시작 |
| 점수 없이 매물만 표시 | 계산용 키 적용·캐릭터 갱신. 미지원 직업/아이템/옵션 여부 확인 |
| 주소 이미 사용 중 | 이전 실행 터미널을 종료하거나 `MAPLE_LOCAL_PORT`로 포트 변경. 확장에도 동일 포트 입력 |

웹 경매장의 내부 인터페이스는 공식 외부 개발자 API 계약이 아니다. 실제 본인 로그인·인증된 API 응답·세션 유지·Windows 실행 확인이 필요하며, 공개 코드·자동 테스트 통과를 실제 계정 연동 성공으로 표현하지 않는다.

## 개발·검증

```bash
npm ci --ignore-scripts
npm test
npm audit --omit=dev
```

- `src/server.mjs`: loopback HTTP API, 로컬 Origin/Host/요청 토큰 확인.
- `src/bridge.mjs` + `extension/`: 실행마다 페어링한 Chrome 연결, 조회·검색 경로만 허용.
- `src/domain.mjs`: 캐릭터 고정, ±30% 필터, 점수·가성비, 30분 감시·기준선·중복·한도 처리.
- `vendor/`: 고정 커밋의 MIT 공개 구현. [출처·수정 내역](vendor/UPSTREAM.md).
- `test/`: 모의 데이터로 계산·전체 어댑터 흐름·감시·한도·인증 경계 검증. `browser-fixture.mjs`는 브라우저 테스트 전용이고 일반 실행에 포함되지 않는다.

단위/통합 테스트의 계정·장비·매물은 가상 fixture다. 실제 키·계정·검색 한도를 사용하지 않는다.

현재 확인한 범위와 실제 계정에서 남은 항목은 [검증 기록](VALIDATION.md)에 정리했다.
