## 주장과 근거의 경계

- Spring Gateway는 OAuth와 DM, Node 포털은 브라우저·검색·계산·감시를 담당한다. 메이플을 RabbitMQ Spring worker로 표현하지 않는다.
- 사용자 한도는 저장된 계정 수이며 동시 처리량 측정값이 아니다. Compose 기본값과 과거 운영의 100명 설정을 구분한다.
- API 최종 스탯을 기준으로 교체 변화량을 계산하지만 전 직업·전 장비·모든 스킬의 실전 DPM이나 환산 점수를 계산하는 것은 아니다. 미지원 조건은 사유가 남는다.
- 공식 이름 검색 누락 검사와 모든 장비의 최신 착용 조건·메타데이터 검증을 구분한다.
- 발송함과 DM ack는 단일 트랜잭션이 아니다. 정확히 한 번 전달이라고 주장하지 않는다.
- PostgreSQL은 조건·상태·요약·알림을 복원한다. 전체 매물 상세는 메모리, 게임 로그인 쿠키는 별도 브라우저 프로필 볼륨이다.
- [PR #28의 PostgreSQL CI](https://github.com/som141/dis/actions/runs/44080255877)는 2026-11-17에 tests 124, pass 124, fail 0, skipped 0이었다. 해당 로그를 재확인했으며 이번 문서 변경에서 테스트를 새로 수행했다는 뜻은 아니다.

## 문서 검증

수정 전후 로컬 파일 링크, 코드·설정 경로와 Git diff 공백 오류를 검사한다. 최초 전체 링크 검사에서 DIS 85개 Markdown과 som-resume 5개 Markdown의 누락 경로는 0개였다(이 감사 기록·빌드 안내 추가 전 집계). 외부 사이트 전체 가용성과 운영 보안·서비스 상태를 새로 검사한 것은 아니다.

som-resume의 이력서에는 장비 비교 기준 개선을 한 줄 추가했다. 포트폴리오는 메이플을 5쪽으로 확장하고 전체 아키텍처·배포 그림과 목차를 갱신했다. 37쪽 PDF의 이미지 로딩·본문 넘침을 자동 확인하고 렌더한 페이지를 시각 검토한다. 기존 음악·주식의 근거 있는 상세 설명은 보존한다.
