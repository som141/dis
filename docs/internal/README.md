# 과거 분석과 작업 기록

이 디렉터리는 구현 과정의 판단·계획·보고서를 보존한다. 문서 안의 “현재”, “완료”, “예정”은 작성 당시를 가리키며, 최신 실행 방법이나 검증 결과를 뜻하지 않는다.

| 기록 | 읽는 목적 |
| --- | --- |
| [analysis/](analysis/README.md) | 과거 코드 분석, Codex 작업 로그, 협업 방식의 맥락 |
| [stock-history/](stock-history/README.md) | 모의투자 기능의 단계별 계획·구현·검증 기록 |

현재 동작은 [구조·계약 문서](../reference/README.md), 실제 명령은 [개발·운영 안내](../operations/README.md), 기능과 첫 실행은 [프로젝트 README](../../README.md)를 우선한다. 과거 기록은 구현 상태에 맞춰 본문을 소급 수정하지 않는다.
