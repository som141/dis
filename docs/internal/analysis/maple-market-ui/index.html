01
선택: 넥슨 로그인 연결

Discord 확인 → 넥슨 로그인·동의 → UID·암호화 토큰을 연결합니다.

02
다중 선택 + 가격 범위

선택 아이템 OR, 스펙·월드·가격은 AND. 기준 예산 30억이면 21~39억입니다.

03
체크박스로 기간 알림

JDA 6.7.0 Modal의 Checkbox·RadioGroup으로 설정합니다.

04
서버 감시 → Discord DM

초기 매물은 기준선으로 두고, 이후 조건을 만족한 새 매물만 알립니다.

연동 확인 상태

넥슨 캐릭터 키와 경매장 인증은 별개입니다. 서버용 경매장 조회·주기 감시와 Open ID 승인과 경매장 권한은 별도로 확인해야 합니다.

이 시안은 외부 API·OAuth·암호화 DB·실제 DM을 연결하지 않습니다. 실제 로그인·토큰 수집을 하지 않는 시안입니다.
