로그인으로 계정을 연결하세요.

개인 API 키를 복사하지 않고, 넥슨 로그인과 정보 제공 동의로 연결합니다.

동작 설명용 시안입니다. 실제 Discord·넥슨 로그인이나 토큰을 수집하지 않습니다. 프렌즈 접근·프로덕션 검수가 필요합니다.

1. Discord 계정 확인

/api를 실행한 계정과 로그인한 계정이 같은지 확인합니다.

아직 Discord 계정을 확인하지 않았습니다.

2. 넥슨 로그인·정보 제공 동의

실제 서비스에서는 넥슨의 로그인·동의 화면으로 이동합니다. 서비스는 넥슨 비밀번호나 개인 API 키를 받지 않습니다.

동의 항목 예시: 내 캐릭터 목록. 이 동의가 경매장 권한을 포함하지는 않습니다.

공개 닉네임 조회는 연결하지 않고도 사용할 수 있습니다.

3. 캐릭터 이름으로 검색

/아이템 캐릭터:예시히어로
입력한 캐릭터의 직업·월드·현재 장비 기준으로 검색합니다. 내 캐릭터 여부는 동의받은 목록과 따로 대조합니다.
