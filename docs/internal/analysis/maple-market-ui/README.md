# 매물 검색·기간 알림 V3 시안

현재 설계는 사진 입력을 사용하지 않는다. [기능 명세](../MAPLE_GEAR_FEATURE_SPEC_2026-10-23.md) · [기술 명세](../MAPLE_MARKET_TECH_SPEC_2026-10-23.md) · [API 조사](../MAPLE_MARKET_API_CHECK_2026-10-23.md).

실제 로그인 세션·검색 어댑터·계산 코드를 연결한 별도 [개인 로컬 프로토타입](../../../../tools/maple-local-prototype/README.md)을 추가했다. 이 디렉터리는 계속 가상 데이터 UX 시안이며, 실제 로컬 실행은 해당 도구를 사용한다.

- `index.html`: `/아이템 캐릭터` 실행 체험, 입력 캐릭터 기준 개인 패널, 아이템 다중/전체 선택·±30%·기간 알림. 공개 조회는 계정 미연결 상태에서도 가능하다.
- `portal.html`: **별도 웹페이지**의 Discord 확인 → 넥슨 Open ID 로그인·동의·UID 연결·갱신/철회 흐름. 실제 로그인이나 키/토큰 입력은 받지 않는다.
- `architecture.png`: image_gen으로 만든 **이전 V2 키 등록** 설명 그림 보관본. 현재 구조는 기술 명세의 V3 Mermaid를 사용한다.
- `market.css`: 외부 폰트·패키지 없는 공통 스타일.

`/api 화면 → 웹에서 넥슨 계정 연결`로 별도 페이지를 열어 Discord 확인/넥슨 로그인 동의를 체험한다. 기본 검색은 **/아이템 실행 체험 → 캐릭터 이름 입력 → 경매장 연결 예시 → 매물 검색**이다. 이후 알림 설정 → 제출 → 감시 시작 → 새 매물 도착 체험을 제공한다.

API·OAuth·토큰 검증/갱신·암호화·DB·경매장·스케줄러·DM은 실제로 연결하지 않았다. localStorage에는 가상 UID·scope·연결 상태만 있고 실제 API 키/토큰은 없다. 입력한 닉네임은 표시와 대상 ID 분리 체험에 사용하며 스탯은 항상 고정 히어로 예시다. 검색·알림은 가상 데이터다. 외부로 자격증명이나 알림을 보내지 않는다.

예시 카탈로그는 소수 항목이다. 25개 초과 카탈로그의 페이지 유지·전체 선택, 실제 provider별 카탈로그 매핑·조회 범위는 기술 명세의 구현/검증 대상이다. 기본 감시 주기는 사용자 요청에 따라 **30분**으로 표시하며, 제공자 한도·오류 시 지연될 수 있다. 시안은 감시 주기 실행 대신 명시적인 체험 버튼을 사용하며, 조건 변경 시 재확인이 필요하다.

시안은 단일 감시와 신규 발견 이벤트를 재현한다. 가격 하락 체크박스는 설정 화면만 제공하며, 실제 가격 변경 감지·다중 감시·서버 재시작 복원은 후속 구현 대상이다.

2026-10-23 Chromium/Playwright에서 별도 웹 페이지 열기, 계정 불일치 거절, 가상 연결 상태만 저장, 캐릭터/경매장 연결 상태 분리, 전체 선택/해제, ±30%와 엄격 상한, 미지원 모델의 스펙 검색, 기간 동의·초기 기준선·신규 조건 판정·중복 억제, pause/만료, 조건 변경 재확인, 390px 폭을 확인했다. JavaScript 오류·외부 요청·새 Markdown 로컬 링크 오류는 없었다. 이는 실제 외부 인증/검색/DM 검증을 뜻하지 않는다.

V3에서는 `/아이템` 닉네임 입력·대상 ID 고정, 넥슨 미연결 상태의 공개 검색, 별도 웹의 Discord→넥슨 동의·가상 UID/scope 연결·갱신 UI, 연결 해제와 공개 감시의 분리, 다른 캐릭터 조회 시 기존 감시 대상 유지까지 추가 확인했다. 실제 토큰 발급·갱신은 하지 않았다.

저장소 루트에서 다음 명령으로 열 수 있다.

```bash
python3 -m http.server 8766 --directory docs/internal/analysis/maple-market-ui
```

브라우저에서 `http://localhost:8766`에 접속한다. 바깥 시안 도구와 설명 패널은 실제 Discord UI에 포함하지 않는다.
