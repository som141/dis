# 메이플 장비 비교실 화면 시안

> 이전 V1 시안 보관본입니다. 사진 없이 API로 검색·감시하는 현재 설계는 [V2 시안](../maple-market-ui/index.html)과 [현재 기능 명세](../MAPLE_GEAR_FEATURE_SPEC_2026-10-23.md)를 사용합니다.

- `index.html`: 브라우저에서 직접 눌러볼 수 있는 독립 HTML. 외부 폰트·패키지·API 요청이 없다.
- `design-board.png`: image_gen으로 만든 Figma 스타일 컨셉 보드. 실제 Discord 캡처나 `.fig` 파일은 아니다.
- [기능·JDA·구현 명세](../MAPLE_GEAR_FEATURE_SPEC_2026-10-23.md)

HTML을 열고 시안 도구의 **예시 매물 3개 채우기**를 누른 뒤 **비교하기**, **자세히 볼 매물 선택**, **두 개 비교**, **조건 변경**, **결과 저장**을 체험한다. 매물 추가 → 스크린샷/직접 입력 → 확인/수정 흐름도 제공한다.

모든 캐릭터·매물·가격은 가상이다. 이미지는 서버에 업로드하지 않고 OCR은 예시로 재현한다. 실제 API·AI·Discord·DB 연결이 없다. 숫자는 앞서 설명한 제한된 히어로 장갑 모델로 브라우저에서 계산한다. 저장 버튼은 이 시안에서만 브라우저 localStorage를 사용하며, 브라우저가 막으면 메모리로 대체한다. 시안의 지원 부위는 장갑뿐이다.

바깥 도구/설명 패널은 설계용이다. 실제 Discord에 구현할 부분은 가운데 채팅 카드와 Modal이며, 박스 내부의 임의 텍스트 입력·웹뷰를 요구하지 않는다. 배색·간격은 컨셉이며 Discord 클라이언트별 렌더링은 달라질 수 있다.

## 확인한 동작

2026-10-23 Chromium/Playwright에서 빈 후보의 비교 차단, A/B/C 점수, 상세·B→C 비교, 예산 10억/1억 필터, 저장 결과 복원, 잠재 입력 검증·수정·미지원 제외, 동일 성능의 고가 후보 제외, 업로드 예시→확인, 세션 만료 복귀·Escape 닫기, 390px 폭의 가로 넘침 여부를 확인했다. JavaScript 오류와 외부 API 요청은 없었다.

이는 HTML 시안의 검증이다. 실제 Discord PC·모바일 클라이언트, API·OCR 정확도, 캐릭터 스탯 복원과 계산 모델의 실서비스 검증은 기능 명세의 후속 구현 단계에 포함한다.

파일 미리보기를 제한하는 환경에서는 저장소 루트에서 다음 명령으로 로컬 HTTP 미리보기를 열 수 있다.

```bash
python3 -m http.server 8765 --directory docs/internal/analysis/maple-gear-ui
```

브라우저에서 `http://localhost:8765`로 접속한다.
