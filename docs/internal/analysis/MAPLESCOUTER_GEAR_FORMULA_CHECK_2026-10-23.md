# 환산주스탯의 템환산 계산식 조사

확인일: 2026-10-23 (KST) · 대상: 사용자가 말한 환산 사이트의 템환산 수치

**현재 사이트의 템환산과 동일한 숫자를 재현할 수 있는 완전한 계산식·계수표는 확인한 공개 자료에서 찾지 못했다.** 일반 환산·헥사환산의 의미와 별도 지표인 아이템스코어의 산정 원리는 공개 글에서 확인했다. “공식이 어디에도 공개되지 않았다”거나 “수학적으로 재현할 수 없다”는 결론은 아니다.

## 지표를 먼저 구분해야 한다

| 지표 | 확인한 내용 | 근거의 한계 |
| --- | --- | --- |
| 일반 환산과 헥사환산 | 인벤 사용자 가이드는 두 값의 차이를 6차 강화 진행도로 설명하며, 6차 스킬을 모두 마스터하면 같아진다고 안내한다. | 사용자 작성 가이드의 설명이다. 사이트의 최신 계산식·직업별 계수를 공개한 자료는 아니다. |
| 커뮤니티의 템환·헥환 표현 | 메이플 인벤 질문 게시판에 두 값을 구분하는 실제 질문들이 있다. 이번 요청은 개별 장비 점수 대신 캐릭터에 표시되는 템환산을 대상으로 읽었다. | 통칭을 사이트 내부 필드명·수식과 동일하다고 단정하지 않는다. |
| 아이템스코어 | 쿠제스의 2024년 글은 기준 아이템을 100점으로 삼고, 주스탯으로 환산한 차이 10당 1점을 가감한다고 설명한다. | 부위별 아이템 점수의 설명이다. 캐릭터의 만 단위 템환산 계산식과 다르며 현재 동일한 기준이 유지되는지도 확인하지 않았다. |
| 아이템스코어 비교모드 | 목표 템환 구간의 평균적인 해당 부위 아이템을 0점으로 놓고 주스탯 환산 차이 10당 1점을 가감한다. | 목표 구간·부위·종류별 기준 자료와 통상 스펙 효율 값이 추가로 필요하다. |

일반 환산과 헥사환산의 설명은 [Flame의 인벤 가이드](https://www.inven.co.kr/board/maple/2304/47723)의 캐릭터정보 부분에서 확인했다. 해당 글은 2026-06-24 작성이며 공식 운영 문서가 아니라 사용자 설명이다.

## 템환산의 정확한 산식으로 확정할 수 없는 부분

템환산을 단순히 장비 주스탯을 합산하거나, 전투력에 고정 상수를 곱한 값으로 계산한다고 확인한 근거는 없다. 쿠제스의 [육각형 설명](https://www.inven.co.kr/board/maple/2304/46134)은 같은 직업·시드링의 여러 기준 스펙과 비교하는 구조, 그리고 패시브·버프 지속시간·레벨·시드링 등 환산에 영향을 주는 요소를 설명한다. 이 글은 육각형에 대한 설명이므로 이를 곧바로 전체 템환산 공식으로 사용해서도 안 된다.

캐릭터 데이터를 점수로 바꾸는 과정을 기호로 표현하면 다음과 같다.

```text
템환산 = F(캐릭터 정보, 적용 세팅, 직업별 처리, 기준 모델, 계산 버전)
```

이는 필요한 정보의 범주를 표현한 것이며 MapleScouter가 공개한 수식이 아니다. 함수 F의 전체 정의·계수·기준표를 확보했다는 의미도 아니다.

동일 수치 재현을 주장하려면 다음이 더 확인돼야 한다.

- 일반 환산과 헥사환산에서 6차 강화·스탯 효과를 처리하는 정확한 방법.
- 입력 능력치·세팅·패시브를 결합하는 수식과 직업별 예외 처리.
- 점수로 환산하는 기준 모델·보정값·계수표.
- 패치 적용 버전, 반올림·버림 등 계산 세부 사항.

이 자료를 확보하지 않은 상태에서 `주스탯 × a + 공격력 × b` 같은 식이나 자체 모델의 값을 사이트의 템환산 공식이라고 제시할 수 없다.

## 별도로 공개된 아이템스코어 산식

쿠제스의 [아이템스코어·비교모드 설명](https://www.inven.co.kr/board/maple/2304/39762), 2024-06-15:

```text
기본모드 점수 = 100 + (내 아이템의 주스탯 환산값 − 기준 아이템의 주스탯 환산값) / 10

비교모드 점수 = (내 아이템의 주스탯 환산값 − 목표 구간 기준 아이템의 주스탯 환산값) / 10
```

위 식은 글의 점수 가감 설명을 수식으로 정리한 것이다. 글은 개인별 효율 대신 통상 스펙 효율을 쓴다고 설명하고, 세트 효과도 러프하게 반영한다고 밝힌다. 따라서 여기서 “주스탯 환산값”은 툴팁의 주스탯 숫자 하나를 뜻하지 않는다.

기본모드의 기준 세팅, 통상 효율, 아이템별 세트 효과 배분, 반지·펜던트의 비교 대상 규칙까지 필요하다. 위의 선형 점수식만으로 동일한 점수를 재현할 수 있는 것은 아니다. 더욱이 **이 식을 캐릭터 템환산 산식으로 사용하면 안 된다.**

## 봇의 매물 추천에 주는 의미

현재 확보한 자료만으로 “이 매물을 끼면 사이트 템환산이 정확히 1,234 오른다”는 결과를 제공할 수는 없다.

매물 비교용 독립 계산 모델을 구현한다면, 동일 캐릭터·조건에서 장비를 바꾸기 전후의 모델 출력으로 다음을 계산할 수 있다.

```text
모델상 데미지 상승률(%) = (교체 후 모델 출력 / 교체 전 모델 출력 − 1) × 100
```

이 비율식은 일반적인 전후 비교 정의다. 정확한 모델 출력 자체는 스탯·세트·직업·스킬·적 방어율 등 지원 조건을 구현하고 검증해야 얻을 수 있다. 이를 사이트의 템환산 증가량으로 바꿀 수 있다는 뜻은 아니다.

템환산과 동일한 점수가 필수라면 운영자가 공개한 수식·계수표가 있는지 또는 허용된 계산 연동을 제공하는지 확인해야 한다. 이전에 확인한 [외부 API 조건](MAPLESCOUTER_API_CHECK_2026-10-23.md)과도 구분해서 검토한다.

## 조사 범위

- 메이플 인벤 팁·질문·자유 게시판에서 환산·템환 관련 글을 검색하고, 위 설명 글의 본문을 읽었다. 댓글은 현재 읽은 HTML에서 본문을 확보하지 못해 근거로 사용하지 않았다.
- MapleScouter 공개 가이드·아이템랭킹·캐릭터 페이지의 반환 HTML을 확인했다. 캐릭터 페이지는 로딩 안내 상태였으므로 최신 점수·툴팁을 읽었다고 주장하지 않는다.
- 쿠제스의 [기본문서 안내 글](https://www.inven.co.kr/board/maple/2304/40452)에 연결된 공개 Google 문서는 클라우드의 목적지 정책 403으로 본문을 읽지 못했다. 따라서 그 문서에 산식이 있는지까지 검증하지 않았다.
- 이미지 호스트도 목적지 정책 403으로 차단돼 글에 첨부된 이미지는 확인하지 못했다. 글의 텍스트 설명을 근거로 사용했다.
- 계산 서버 호출, 사이트 키·토큰 추출, 비공개 계산 코드 분석은 수행하지 않았다.
