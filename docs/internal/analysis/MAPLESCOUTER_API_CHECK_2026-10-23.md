# 환산주스탯 외부 API 제공 여부 확인

확인일: 2026-10-23 (KST) · 대상: MapleScouter 공식 사이트 및 공개 연동 사례

**외부 개발자가 자유롭게 이용할 수 있는 공개 API 제공은 확인되지 않았다. 공식 이용약관은 봇·MCP 등의 자동 접근과 다른 서비스의 백엔드로 계산 기능을 사용하는 행위를 명시적으로 금지한다.** Discord 봇에서 환산 계산을 직접 호출하는 구성은 운영자와의 별도 협의·허용 여부를 확인한 뒤 결정해야 한다. 비공개 제휴 API의 제공 여부는 아직 확인하지 않았다.

## 공식 자료에서 확인한 내용

이번 확인에서는 공식 홈페이지 접속에 성공했다. 이전 보고서의 접속 제한은 당시의 관측이며, 현재 확인 결과와 구분한다.

| 자료 | 확인 결과 |
| --- | --- |
| [홈페이지](https://maplescouter.com/ko) | 캐릭터 조회·시뮬레이터·문의 링크가 있다. 공개 개발자용 API 문서·키 발급 안내를 확인하지 못했다. |
| [사용자 가이드](https://maplescouter.com/ko/guide) | 일반 사용자 가이드·업데이트·FAQ 메뉴를 확인했다. 확인한 응답에서 외부 개발자 API 안내는 찾지 못했다. |
| [사이트맵](https://maplescouter.com/ko/sitemap) | 계산·최적화·아이템메이커 등 웹 기능을 안내한다. 외부 API 제공 안내를 확인하지 못했다. |
| [이용약관](https://maplescouter.com/ko/agreement) | API 정의와 자동 접근·백엔드 사용 등의 금지 규정이 있다. 부칙의 시행일은 2026-07-11이다. |
| [공식 링크 모음](https://maplescouter.com/ko/quick-link) | 공식 Discord와 문의 채널을 안내한다. |

약관 제15조의 관련 문구:

> 자동화된 수단 (봇·스크립트·크롤러·스크래퍼·헤드리스 브라우저·MCP 등)을 이용하여 서비스 또는 서비스의 API에 접근하는 행위

> 서비스의 계산·환산 기능을 타 서비스·제품·도구의 백엔드 또는 데이터 소스로 사용하는 행위

같은 조에는 API 키·토큰·엔드포인트의 무단 추출·재사용, 접근제어 우회, Origin·Referer 위조 등도 금지행위로 명시돼 있다. 따라서 내부 계산 요청 경로를 발견했다는 이유로 봇 연동이 허용됐다고 볼 수 없다. `robots.txt`의 검색 수집 설정도 API 연동 허가를 대신하지 않는다.

## 공개 프로젝트와의 관계

- [MapleDoro의 계산 요청 구성 코드](https://github.com/chablades/mapledoro/blob/7528835edcff43a1a6a3425a01b55959c139369b/src/features/characters/scouter/scouterApi.ts)는 사이트 계산 요청에서 관찰한 형식에 맞춰 데이터를 구성한다고 설명한다. 공개 API 계약이나 운영자 승인 근거로 볼 수 없다.
- [MapleDoro PR #183](https://github.com/chablades/mapledoro/pull/183)은 2026-10-21에 환산 API 요청을 없애고 자체 근사 계산으로 바꾼다고 설명한다. 변경 이유가 약관 때문이라고 단정할 근거는 없다.
- [Hascone README](https://github.com/doIIarplus/hascone/blob/d59aad6ac7a18a2f08a83f6df1bac9b89312ebd0/README.md)에는 브라우저 검증·세션 재사용으로 계산하는 흐름이 있다. 이것도 외부 개발자용 API 발급·사용 허가를 증명하지 않는다.
- [MapleBot README](https://github.com/SoochanP/maplebot)는 `!환산`이 환산 사이트 링크를 만들어 주는 명령이라고 명시한다. 링크 제공과 환산값을 서버에서 계산·수집하는 연동은 별개다.

이번에는 공식 안내를 읽고 공개 프로젝트 코드를 조사했다. 환산 계산 서버에 계산 요청을 보내거나, 사이트의 키·토큰을 추출·사용하거나, 브라우저 검증을 우회하지 않았다.

## DIS 설계에 반영할 사항

1. `환산 사이트 직접 계산 연동`은 운영자 협의 전까지 미확정 의존성으로 둔다. 개인의 넥슨 Open API 키가 MapleScouter 외부 연동 권한을 부여하지는 않는다.
2. 공식 외부 연동이 허용된다면 지원 계산·인증·초당 및 일일 한도·캐시·결과 표시·비용·버전 변경 정책을 확인한 후 어댑터를 구현한다.
3. 협의 전의 장비 추천은 넥슨 데이터와 사용자가 제공한 매물, 독립적으로 검증한 계산 모델을 사용한다. 그 모델의 점수를 환산 사이트의 환산값으로 표시하지 않는다.
4. 사용자가 직접 확인한 결과와 링크를 참고 자료로 받을 수 있으나, 그 결과를 자동 재수집하거나 환산 계산 로직을 복제하는 설계로 확장하지 않는다. 서비스 내 저장·재표시 범위도 협의 시 함께 확인한다.

### 운영자 문의 초안 — 전송하지 않음

> Discord에서 사용자의 캐릭터와 예산에 맞는 장비 매물을 비교하는 비공식 봇을 검토하고 있습니다. MapleScouter의 캐릭터 환산 및 가상 장비 교체 계산을 외부 서비스에서 사용할 수 있는 제휴 API나 별도 허가 절차가 있는지 문의드립니다. 가능하다면 지원 기능, 인증 방식, 호출 한도, 결과 캐시·표시 조건, 비용과 출처 표시 기준을 안내받고 싶습니다. 허가 전에는 내부 API를 호출하는 연동을 구현하지 않겠습니다.

문의 경로는 [공식 홈페이지](https://maplescouter.com/ko)의 문의하기 또는 [공식 링크 모음](https://maplescouter.com/ko/quick-link)에서 확인할 수 있다. 문의는 작성만 했으며 전송하지 않았다.
