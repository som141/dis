# 메이플 인벤 조사 범위와 경매장·AI 장비 추천 사례

작성일: 2026-10-23 (KST) · 상태: 공개 구현 사례 조사, 인벤 원문 조사는 접속 제한으로 미완료

후속 확인: [환산주스탯 공식 약관·외부 API 조사](MAPLESCOUTER_API_CHECK_2026-10-23.md)에서 자동 접근·타 서비스 백엔드 사용 금지 규정을 확인했다. 아래 공개 구현 사례가 환산 측의 이용 허가를 받았다는 뜻은 아니다.

후속 요청에 따라 사용자 고충 조사의 1차 자료를 **메이플 인벤 게시글·댓글**로 좁힌다. 경매장 분석과 AI 장비 추천에는 이미 공개 구현 사례가 있다. 이번에 확인한 것은 소스와 문서의 존재·처리 흐름이며, 실제 서비스 접속·넥슨 로그인·추천 정확도 검증은 수행하지 않았다.

## 메이플 인벤 조사 상태

`https://www.inven.co.kr/board/maple/2304` 접속이 클라우드 프록시에서 `Tunnel connection failed: 403 Forbidden`으로 거절됐다. 현재 실행 환경의 허용 도메인에 인벤이 없다. 따라서 인벤 이용자가 어떤 불편을 가장 자주 겪는지, 아래 도구가 인벤에서 어떤 반응을 얻었는지는 아직 판단할 수 없다. GitHub README의 설명을 인벤 게시글이나 댓글로 인용하지 않는다.

기존 명시적 허용 도메인을 보존하면서 인벤 웹·모바일, 검색, 넥슨 문서·경매장, 환산 사이트의 도메인을 환경 설정 초안에 추가했다. **초안 저장은 실행 환경에 대한 적용이 아니다.** 환경 설정에 반영된 뒤 실제 접속 성공을 확인해야 원문 조사를 진행할 수 있다.

원문 접근 후 다음 범위로 조사한다. 아래는 조사 설계이며 확인한 게시글의 집계 결과가 아니다.

| 조사 대상 | 검색할 주제 | 글·댓글에서 추출할 내용 |
| --- | --- | --- |
| 팁과 노하우, 직업별 게시판 | 템세팅, 무보엠, 방무, 가성비, 스펙업 순서 | 직업·목표 보스·현재 세팅·예산, 작성자의 추천 이유·조건, 반론 |
| 질문·시세 평가 글 | 이 가격, 시세, 직작, 완작, 매물 비교 | 월드·가격·옵션·작성 시점, 답변에 추가로 필요했던 정보 |
| 도구 소개·후기 | 경매장, AI, 추천, 계산기, 환산 | 실제 입력 방식, 이용자가 지적한 오류·번거로움, 개발자의 대응 |

최근 약 60일의 질문·후기를 우선 보고, 가이드는 과거 글도 현행 패치와의 관계를 확인한다. 홍보 글과 사용자 질문, 같은 작성자의 중복 글을 구분한다. 결과는 `원문 URL·작성일·직업/월드·예산·불편·해결 제안·댓글 반론·검증 상태`로 기록한다. 표본이 확보되기 전에는 빈도나 수요 순위를 제시하지 않는다.

공개 프로젝트 MAGPT의 [자료 후보 목록](https://github.com/limchanggeon/MAGPT/blob/1d71919fc1c6d385bdc3d412db028d02f53098fd/docs/research/2026-10-07-maple-sources.md)에서 [템세팅 가이드 링크](https://m.inven.co.kr/board/maple/2304/48305?vtype=mobile)를 발견했다. 이는 후속 탐색 후보이며, 이번 조사에서 인벤 원문을 읽거나 내용을 검증했다는 뜻은 아니다.

## 경매장 분석·장비 추천을 구현한 사례

### 1. Maple Auction MCP: AI 대화와 경매장 검색 연결

- 자료: [프로젝트 README](https://github.com/oyc0401/maple-auction-mcp/blob/d01119598479225946c3a7defa9be6f2f1b93295/README.md).
- 확인 코드: [MCP 도구 등록](https://github.com/oyc0401/maple-auction-mcp/blob/d01119598479225946c3a7defa9be6f2f1b93295/server/src/mcp.ts), [매물 교체 계산 연결](https://github.com/oyc0401/maple-auction-mcp/blob/d01119598479225946c3a7defa9be6f2f1b93295/server/src/auction/service.ts), [브라우저 요청 처리](https://github.com/oyc0401/maple-auction-mcp/blob/d01119598479225946c3a7defa9be6f2f1b93295/extension/src/api.ts).

Claude·Codex 등에서 자연어로 경매장을 검색하도록 연결하는 도구다. README에 “내가 낄 만한 카데나 무기 데미지 증가율 높은 순으로 찾아줘”라는 사용 예가 있다.

처리 흐름은 **AI → MCP 검색 도구 → 로컬 Chrome 확장 → 로그인된 넥슨 경매장 → 검색 결과 → 비교·설명**이다. 확장 코드는 브라우저의 로그인 상태를 이용해 요청하며, 공식 캐릭터 Open API와 경매장 접근은 별도 경로다.

넥슨 Open API 키를 추가하는 개발 모드에는 현재 착용 장비 조회·갱신과 슬롯별 `finalDamageChangeRate` 계산 연결이 있다. 키나 캐릭터 정보가 부족하면 계산 불가 사유를 반환하는 코드도 확인했다. 계산 모델의 직업별 정확도와 환산 사이트와의 일치 여부는 검증하지 않았다.

**우리에게 주는 시사점:** AI가 질문을 이해하고, 실제 검색·계산 도구가 제공한 매물로 답하는 구성이 이미 존재한다. 다만 사용자 PC의 확장·로그인에 의존하므로 서버의 Discord 봇이 그대로 대신 실행할 수 있는 구성은 아니다. 서비스로 도입하려면 공식 허용 범위와 브라우저 연결·세션 관리를 별도로 검토해야 한다.

### 2. maple-optimizer: 장비 툴팁을 AI로 읽고 매물을 평가

- 자료: [README](https://github.com/bat1120/maple-optimizer/blob/55c91fdad042d1602590f47dfafc47ec6fb4357c/README.md).
- 확인 코드: [이미지에서 매물을 추출하는 비전 호출](https://github.com/bat1120/maple-optimizer/blob/55c91fdad042d1602590f47dfafc47ec6fb4357c/server/vision.py), [화면 평가·매물 비교·예산 최적화 경로](https://github.com/bat1120/maple-optimizer/blob/55c91fdad042d1602590f47dfafc47ec6fb4357c/server/app.py).

공유한 게임·웹 경매장 화면에서 장비 툴팁을 AI가 읽고, 캐릭터의 현재 장비와 비교하는 구현이다. 매물의 가격 대비 효율, 직작 대비 비교, 예산 내 후보 조합과 AI 상담을 설명한다.

코드에서는 `OpenAI Responses API`에 이미지와 JSON 스키마를 전달한다. 읽지 못한 값은 `null`로 두라는 지시, 장착 중인 장비와 판매 매물의 분리, 옵션 합계 검증이 있다. `/api/vision/listings`에서 추출 결과를 장비 평가 서비스로 연결하고, `/api/character/{name}/optimize`에서 예산과 후보를 받는다.

**확인한 범위:** AI 판독 → 구조화 → 장비 평가로 이어지는 코드가 있다. 실제 API 키를 넣어 실행하거나 출력 정확도·인게임 효과를 검증하지 않았다. README의 “실딜” 표현을 실제 보스전 성능이 보장된다는 뜻으로 받아들이지 않는다.

**우리에게 주는 시사점:** Discord에 올린 매물 스크린샷을 입력으로 받는 버전부터 구현할 수 있다. 서버가 사용자의 경매장 로그인 정보를 취급하지 않고도 후보 장비 비교를 시작할 수 있다. 이미지 숫자의 오인식은 사용자 확인과 코드 검증으로 보완해야 한다.

### 3. MapleGearSim: 예산·직작 비용·구매 상한가 비교

- 자료: [README](https://github.com/gnssl98/MapleGearSim/blob/65842083cb63d16cf43c4fe7acc7b7dbb33d8c40/README.md).

개인용 장비 시뮬레이터로 직작 비용의 기대값·분포, 완제품 구매 상한가, 예산별 업그레이드 조합을 설명한다. 경매장 가격은 직접 기록하는 방식이다.

이번에는 README만 확인했다. 계산기·추천 도구 사례이며 AI 기반임을 확인한 사례는 아니다. 표에 적힌 환산 상승량의 계산 정확도도 검증하지 않았다.

**우리에게 주는 시사점:** 장비 추천에서 중요한 것은 대화 모델 외에도 가격·옵션·세트·강화 비용을 비교하는 계산 모델이다. 매물을 자동 검색하지 않아도 사용자 입력으로 시작할 수 있다.

### 4. maple-item-recommend: 추천 기능의 완성 범위를 확인할 필요가 있는 사례

- 자료: [README](https://github.com/ontalk/maple-item-recommend/blob/b5bee24f5d4947bbe543d7b3c4e58919cbb71fb8/README.md).
- 확인 코드: [추천 엔진](https://github.com/ontalk/maple-item-recommend/blob/b5bee24f5d4947bbe543d7b3c4e58919cbb71fb8/src/lib/recommendation-engine.ts), [확장 통신](https://github.com/ontalk/maple-item-recommend/blob/b5bee24f5d4947bbe543d7b3c4e58919cbb71fb8/extension/background.js).

README는 경매장 기반 템세팅·비용 효율 추천을 설명한다. 확장에서 로그인한 경매장 탭을 찾아 요청을 전달하는 코드가 있다.

그러나 확인한 `generateRecommendations` 경로는 `TWO_HUNDRED_MILLION_MINIMUM` 고정 기준표와 고정 추정 비용을 사용한다. `source: 'template'`, 전 서버 표본 DB 미연결 안내, `expected_stat_increase: 0`도 보인다.

전체 프로젝트의 모든 기능이 템플릿이라는 뜻은 아니다. 다만 이 추천 경로를 실시간 시세·개인별 정확한 상승량까지 검증된 엔진의 사례로 소개하기는 어렵다. 도구를 선정할 때 README의 목표와 실제 지원 범위를 나눠 확인해야 한다.

## 유료 AI API를 연결한다면

외부 AI API를 호출해 장비 추천 서비스를 만들 수 있다. 봇 서버에 GPU가 없어도 가능하다. 이미지 판독·대화 설명의 사용료는 제공자 API 요금과 호출량에 따라 발생하며 ChatGPT Plus 구독과 별개다. 특정 모델 이름이나 요금은 이번 조사에서 공식 문서로 재확인하지 않았다.

추천 처리 흐름은 다음과 같다.

```mermaid
flowchart LR
    U[캐릭터명·예산·매물 스크린샷] --> V[AI 옵션 판독]
    V --> H[사용자 확인·수치 검증]
    N[넥슨 API: 현재 장비] --> E[장비 비교·예산 계산]
    H --> E
    E --> A[AI 추천 이유 설명]
    A --> D[Discord 본인에게 결과 표시]
```

첫 범위는 **같은 부위의 매물 2~5개 비교**가 적절하다. 판독 뒤에 옵션·가격을 확인시키고, 검증한 장비 교체 모델로 후보를 평가한 다음 이유를 설명한다. 지원 직업·장비·패치 범위를 제한하고 모델 밖 조건은 계산하지 않는다.

| 판단 | 필요한 근거 |
| --- | --- |
| 현재 장비보다 어떤 옵션이 달라지는가 | 현재 장비와 매물의 옵션·프리셋·세트 변화 |
| 내 캐릭터에 어느 후보가 유리한가 | 직업별 효과와 검증한 교체 계산, 목표 보스·사냥 조건 |
| 예산 안에서 무엇을 살 수 있는가 | 매물 가격·예산·부위별 중복 제약 |
| 시세보다 싼 매물인가 | 같은 월드·시점·옵션의 비교 자료. 판매 호가와 실제 체결가를 구분해야 함 |
| 직작보다 유리한가 | 패치·이벤트·할인·스페어 값을 반영한 강화 비용 분포 |

매물 한 장만으로 시장 전체의 최저가·적정 시세를 확정할 수는 없다. 먼저 “올린 후보 중 무엇이 나에게 유리한가”를 제공하고, 충분한 비교 자료가 확보됐을 때 시세 평가로 확장하는 것을 추천한다.

**현재 결론:** AI를 이용한 경매장 검색·화면 판독·템 비교의 공개 구현은 있다. 우리 봇도 이를 설계할 수 있다. 인벤 이용자의 구체적인 불편·반응·도구 평가는 원문 접근이 확보된 뒤 별도로 조사해야 한다.
