# DIS 시작 배경: 사용자 경험과 2024년 공개 기록

확인일: **2026-10-27** · 아래 날짜는 별도 표시가 없으면 **한국시간(KST)**이다.

## 1. 사용자가 확인한 사실

사용자는 이번 작성 과정에서 다음 두 가지를 추가로 설명했다.

- 2024년에 기존 Discord 봇들이 먹통이 되는 일을 겪었다.
- 현재 DIS를 지인 약 30명과 함께 사용하고 있다.

이 내용은 사용자가 설명한 실제 경험과 현재 이용 범위로 반영한다. 다만 당시 사용한 봇 이름·정확한 날짜·에러 로그는 이 설명만으로 특정할 수 없다. 특정 서비스의 종료 공지를 말하는지, 음악 재생이 반복적으로 실패했던 상황을 말하는지도 구분하지 않는다.

따라서 시작 배경에서는 **기존 봇이 제대로 동작하지 않았던 경험과 직접 봇을 만들어 사용하게 된 과정**을 설명할 수 있지만, 아래 외부 이슈 중 하나를 사용자가 겪은 사건이라고 단정해서는 안 된다.

현재 이용 범위는 **지인 약 30명과 함께 사용**으로 쓴다. 동시 접속자 30명, 일간/월간 활성 사용자 30명, 음악 동시 재생 30명 등의 지표로 바꾸지 않는다. 사용 기간이나 요청량도 별도의 기록 없이 계산하지 않는다.

## 2. 2024년의 공개 1차 자료

Lavalink·Lavaplayer·youtube-source는 Discord 음악 봇에서 사용되는 오디오 처리 관련 공개 프로젝트다. 다음은 해당 프로젝트의 당시 이슈·유지보수자 답변·릴리스 기록을 직접 읽고 정리한 내용이다. **Discord 전체 장애가 한 번에 발생했다는 공식 사고 보고서가 아니라**, YouTube 재생 실패가 보고되고 관련 구현이 변경되던 시기의 기록이다.

## 3. 포트폴리오에 반영할 표현

사용자의 경험은 다음과 같이 간단히 설명할 수 있다.

> 2024년 기존 Discord 봇들이 제대로 동작하지 않는 일을 겪은 것이 직접 봇을 만들게 된 계기였습니다. 현재는 지인 약 30명과 함께 DIS를 사용하고 있습니다.

당시 업계 맥락을 덧붙일 필요가 있다면 별도 문장과 출처로 분리한다.

> 비슷한 시기 음악 재생에 사용되는 공개 라이브러리에서도 YouTube 로그인 요구와 곡을 불러온 뒤 재생하지 못하는 문제가 보고됐습니다. 다만 제가 사용하던 봇의 당시 문제와 동일한 원인이었는지는 확인하지 못했습니다.

첫 문장은 사용자 설명을 정리한 시작 배경이고, 두 번째 문단은 공개 기록을 요약한 외부 맥락이다. 외부 사례가 사용자 자신의 경험을 대신 입증하는 구조로 쓰지 않는다.

## 4. 사건·시점의 구분

- **2021년 Groovy/Rythm 종료 사례를 2024년 사용 경험의 사건으로 바꾸어 쓰지 않는다.** 이번 근거표는 2024년에 생성된 이슈와 발표된 릴리스만 사용한다.
- **2024년 외부 음악 재생 실패 보고와 2026년 DIS의 무음 문제 해결은 별개다.** 비슷한 증상이 있더라도 같은 장애나 같은 수정 건으로 합치지 않는다.
- Discord 플랫폼 전체가 중단됐거나, 모든 음악 봇이 동시에 영구 종료됐다는 결론을 내리지 않는다.
- YouTube의 공식 정책 변경 시점·원인이 확정됐다고 쓰지 않는다. 확인한 것은 공개 프로젝트의 문제 보고와 대응 기록이다.
- 지인 약 30명의 이용은 대규모 서비스 트래픽이나 부하 테스트 수치를 입증하는 자료가 아니다.

특정 봇 이름·공식 공지·사용 당시 기록이 추가로 확인되면 사건을 더 구체적으로 연결할 수 있다. 그 전까지는 현재 확인된 경험과 위 공개 자료의 범위 안에서 작성한다.
