# 윤영주

Java를 중심으로, 직접 사용하는 Discord 봇을 만들고 운영 중 생긴 문제를 개선하고 있습니다.

[GitHub](https://github.com/som141) · [DIS 프로젝트](https://github.com/som141/dis) · [DIS 상세 포트폴리오](PORTFOLIO.md)

## 대표 프로젝트 · DIS

**음악 재생과 주식 모의투자를 제공하는 Discord 봇**\
개발 기록 2025.06~ · 개인 프로젝트 · 개발 및 운영\
[저장소](https://github.com/som141/dis)

2024년 Discord 봇들이 동작하지 않던 경험을 계기로 음악 봇을 개발하고 GCP에 올렸습니다. 현재 지인 약 30명과 사용하며, 음악 재생 외에 가상 자금으로 주식을 사고팔고 계좌·순위를 조회하는 기능을 제공합니다.

- **음악이 나오지 않는 문제 해결:** 재생 안내는 표시되지만 소리가 들리지 않는 상황에서 서버 로그와 외부 음원 요청을 확인했습니다. 인증 상태와 음원 요청 방식의 호환성을 점검해 재생을 복구하고, 나중에 발생한 재생 실패도 원래 요청에 안내하도록 개선했습니다.
- **요청과 답변 연결 개선:** 명령 수신과 실제 작업을 나누면서, 답변할 위치를 저장한 뒤 작업을 보내도록 순서를 정리했습니다. 결과가 빨리 돌아오는 경우에도 이 순서가 지켜지는지 테스트로 확인했습니다.
- **빌드·배포 문제 대응:** 외부 라이브러리 저장소가 올바른 설명 파일 대신 웹페이지를 반환하는 문제에 대응했습니다. 같은 버전의 공식 배포 파일을 사용하고 검증값을 확인하도록 바꿨으며, 변경 후 자동 빌드와 서버 배포 성공을 확인했습니다.

사용 기술: Java, Spring Boot, JDA, LavaPlayer, RabbitMQ, Redis, PostgreSQL, Docker Compose, GitHub Actions.
